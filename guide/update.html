🔄 업데이트 방법 (3단계, 5분이면 끝)

  1. 새 버전 파일 받기 — 아래 버튼으로 업데이트 신청 메일을 보내주시면 최신 파일 다운로드 링크를 보내드려요.
  2. 기존 HTML 파일 덮어쓰기 — 받은 파일(쌤보드·쌤보드클래스 각각)을 지금 쓰시는 HTML이 있는 같은 폴더에 넣으세요. 폴더에 있는 대시보드_설정.json·쌤보드클래스_설정.json 파일은 그대로 두시면 됩니다.
  3. Lively Wallpaper에서 새 파일 등록 — Lively에서 새 HTML을 배경화면으로 지정하면 완료! (파일명이 같으면 벽지 새로고침만 해도 돼요)
✅ 데이터는 안 날아가요. 쌤보드 설정·할 일은 대시보드_설정.json과 구글시트 백업에서, 쌤보드클래스의 자리배치·포인트는 쌤보드클래스_설정.json에서 자동 복구됩니다. 혹시 모르니 업데이트 전에 각 프로그램의 백업 탭에서 💾 내보내기 한 번씩 눌러두시면 완벽!
💡 처음 설치하시거나 자세한 설정법이 궁금하시면 쌤보드 설정 가이드를 참고하세요.

📥 새 버전 받기

아래 버튼을 누르면 신청 메일이 열려요. 보내주신 메일로 최신 파일 링크를 답장드립니다.
