⬇ 다운로드 (v0.4.0)
1
Chapter 1
파일 준비

이지에듀나 스쿨마스터에서 재구성한 연간시간표를 읽어서, 나이스 학기별 시간표 관리 화면에 다른 칸만 자동으로 입력해 주는 크롬 확장 프로그램이에요. 선생님이 하던 "칸 우클릭 → 과목 선택"을 대신 눌러 줍니다.

다운로드 및 압축 해제
1
다운로드
위의 ⬇ 다운로드 버튼(또는 목록 페이지의 다운로드 버튼)으로 zip 파일을 받습니다.
2
압축 해제
zip 파일을 우클릭 → 모두 압축 풀기. 문서 폴더처럼 지우지 않을 곳에 풀어 주세요.
3
파일 확인
나이스시간표입력기_v0.4.0 폴더 안에 manifest.json 파일이 있으면 정상입니다. 설치 방법을 적은 설치방법.txt도 함께 들어 있어요.
⚠️
폴더를 삭제하거나 이동하지 마세요
압축을 푼 폴더는 크롬이 확장 프로그램으로 계속 참조합니다. 폴더를 옮기거나 지우면 확장이 작동하지 않아요.
2
Chapter 2
확장 설치
크롬에 불러오기 (처음 한 번)
1
확장 프로그램 관리 열기
크롬 주소창에 chrome://extensions를 입력합니다.
2
개발자 모드 켜기
오른쪽 위의 개발자 모드 스위치를 켭니다.
3
압축해제된 확장 프로그램 로드
왼쪽 위 압축해제된 확장 프로그램을 로드를 누르고, 1장에서 푼 나이스시간표입력기_v0.4.0 폴더를 선택합니다.
4
툴바에 고정
툴바의 퍼즐(🧩) 아이콘을 눌러 나이스 시간표 입력기 옆의 핀(📌)을 누르면 아이콘이 항상 보여요.
💡
엣지(Edge)에서도 쓸 수 있어요
엣지 주소창에 edge://extensions를 입력하고 같은 방법으로 불러오면 됩니다.
3
Chapter 3
처음 설정
나이스 화면 준비
1
시간표 프로그램에서 저장
이지에듀나 스쿨마스터에서 연간시간표를 고쳤다면 먼저 저장을 눌러 주세요. 확장은 저장된 파일을 읽어요.
2
나이스 학기별 시간표 열기
나이스 로그인 → 학급담임 → 학급시간표 관리 → [학기별시간표관리] 팝업을 열고 [조회]를 누릅니다.
3
패널 열기
툴바의 나이스 시간표 입력기 아이콘을 누르면 오른쪽에 패널이 열리고, 나이스 화면을 자동으로 읽어요.
쓰는 프로그램 고르기 · 폴더 연결 (처음 한 번)
1
프로그램 고르기
패널의 시간표 프로그램에서 학교에서 쓰는 이지에듀 또는 스쿨마스터를 고릅니다. 한 번 고르면 기억해요.
2
폴더 연결
📁 폴더 연결을 누르고 아래 폴더를 고른 뒤, 크롬이 "파일 보기"를 물으면 허용합니다.
· 이지에듀: C:\EasyeduTogether
· 스쿨마스터: C:\Schoolmaster 2026
다음부터는 나이스의 학년도·학기·학년·반에 맞는 파일을 알아서 찾아 읽어요.
쓰는 프로그램을 고르고 폴더를 연결해요
💡
크롬을 다시 켜면
브라우저 규칙상 🔓 폴더 읽기 허용 버튼이 한 번 더 나올 수 있어요. 누르기만 하면 됩니다. 폴더 연결이 어려우면 파일 직접 고르기로 .dat(이지에듀) · year_table.mdb(스쿨마스터)를 골라도 돼요.

Chapter 4
입력하기
미리보기 확인
1
바뀌는 칸 보기
패널이 나이스와 시간표 파일을 비교해서 다른 칸만 골라 보여줘요. 주를 넘기며 확인하고, 칸을 누르면 나이스 표에서 그 칸으로 이동해 깜빡여요.
주별 미리보기 (예시 화면)
미리보기 표 읽는 법
초록바뀔 칸 (오른쪽 위 작은 글자가 원래 과목)
빨강비울 칸 (수업이 없어지는 칸)
파랑이번에 입력한 칸
주황 테두리확인 필요 (헷갈릴 수 있는 칸)
파란 점전담 선생님 수업
입력 · 확인 · 저장
1
나이스에 입력하기
아래 나이스에 N칸 입력하기를 누릅니다. 처음에는 왼쪽 입력 범위에서 한 주만 골라 시험해 봐도 좋아요. 한 학기도 몇 초면 끝나요.
2
확인 필요 살펴보기
멈추지 않고 끝까지 넣은 뒤, 헷갈릴 수 있는 칸만 날짜·교시로 모아 보여줘요. 전담 과목이 새 자리에 들어간 칸은 버튼으로 선생님을 바로 바꿀 수 있어요.
3
저장하고 확인하기
나이스 팝업의 [저장]을 직접 누른 뒤, 패널의 ✓ 저장 확인을 누르면 나이스에 저장된 시간표가 파일과 같은지 검사해 줘요.
확인 필요 — 전담 과목 칸은 선생님을 골라요 (예시 이름)
입력 후 — 저장 전이면 [원래대로]로 되돌릴 수 있어요
🔒
저장은 선생님이 직접
확장은 나이스 화면 안에서 선생님의 클릭만 대신하고, 나이스 서버에 직접 요청을 보내지 않아요. 인증서 로그인과 [저장]은 언제나 선생님이 직접 합니다. 저장하기 전에는 ↩ 원래대로로 입력 전 상태로 돌아갈 수 있어요.
Q
FAQ
자주 묻는 질문
과목이 그대로인 칸은 건드리지 않아요. 바뀌는 칸은 기초시간표의 같은 자리·같은 과목이면 그 선생님, 아니면 담임으로 넣어요. 기초시간표는 나이스 학기 시간표에서 요일·교시마다 가장 많이 나오는 과목·선생님으로 알아내며, 패널의 교사 기준 탭에서 볼 수 있어요. 헷갈리는 칸은 확인 필요에서 칸마다(또는 한꺼번에) 선생님을 고를 수 있고, 고른 건 기억해요.
나이스의 [수업삭제]는 위쪽 편차 표를 바로 다시 계산하지 않는 나이스 쪽 표시 문제가 있어요. 실제 데이터는 정확하니 저장한 뒤 다시 조회하면 맞게 나와요. 패널의 시수 탭은 칸 수를 직접 센 값이라 늘 정확해요.
다른 반 시간표가 잘못 들어가지 않도록, 나이스에서 조회한 학급과 연결한 폴더의 학급·학년도가 다르면 이유를 알려주고 막아요. 나이스 팝업에서 학년·반을 확인하거나 맞는 폴더(이지에듀 C:\EasyeduTogether, 스쿨마스터 C:\Schoolmaster 2026)를 연결해 주세요.
나이스의 행사·휴업일 칸은 건드리지 않고 확인 필요 → 건너뛴 칸에 모아 알려줘요. 학사일정이 서로 다른 것이니 나이스 학사일정이나 시간표 프로그램 쪽을 확인해 주세요.
아니요. 시간표 파일은 선생님 컴퓨터 안에서만 읽고, 외부로 보내지 않아요. 나이스 화면도 선생님의 브라우저 안에서만 읽고 입력합니다.
새 버전 zip을 받아 같은 폴더에 파일을 덮어쓴 뒤, chrome://extensions에서 확장 카드의 새로고침(↺)을 누르면 재설치 없이 업데이트돼요. 연결한 폴더와 설정은 그대로 남아요.
