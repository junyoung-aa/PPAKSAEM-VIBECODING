CHAPTER 1
쌤보드 클래스란?
🚀 3줄 요약
  • 학생 자리배치·칭찬포인트·1인1역할·랜덤뽑기를 한 화면에 모은 학급운영 도구.
  • 쌤보드 프로그램 안에 함께 들어 있어 따로 받을 게 없어요.
  • 모니터가 두 대면 2번째 화면에, 한 대면 그 화면에 띄우면 됩니다.

쌤보드 클래스는 학생 자리배치(랜덤·짝꿍·모둠), 칭찬 포인트, 1인 1역할, 학생 뽑기(돌림판·카드·슬롯)까지 교실 운영에 필요한 기능을 한 화면에 모은 도구입니다. 이미 쌤보드(교사용 대시보드)를 쓰고 있다면 그 짝꿍 제품이고, 안 쓰고 있어도 단독으로 전체 기능을 사용할 수 있습니다.

1-1. 나는 어떤 방법으로 써야 할까?

모니터 구성에 따라 두 가지로 씁니다. 어느 쪽이든 기능은 완전히 같고, 화면에 띄우는 자리만 다릅니다.

🖥️🖥️
듀얼모니터
A. 듀얼모니터 2번째 화면

모니터가 2개라면 주로 보시는 화면엔 쌤보드(대시보드), 아이들에게 보여줄 화면엔 쌤보드클래스를 띄워 항상 보면서 운영할 수 있습니다. 설정 창에서 모니터마다 골라주기만 하면 돼요.

🪑
단독 사용
B. 쌤보드 클래스만 단독

대시보드(날씨·캘린더·할일 등)까진 필요 없고 자리배치·포인트·뽑기만 쓰고 싶다면, 모니터 한 대에 쌤보드클래스만 지정해서 단독으로 쓰시면 됩니다.

항목A. 듀얼모니터B. 단독 사용
따로 설치할 것없음 (쌤보드에 포함)없음 (쌤보드에 포함)
모니터 몇 개?2개 권장1개도 OK
학생 명단 연동직접 설정 (4장)직접 설정 (4장)
이 가이드에서 볼 장1~14장 전체1~14장 전체
💡 이미 쌤보드(본체)를 쓰고 있다면
학생 명단을 새로 만들 필요 없이, 4장에서 쌤보드 본체와 같은 구글시트 URL을 그대로 입력하면 명렬표를 그대로 불러옵니다 (읽기 전용이라 본체 데이터에 영향 없음).
🏠 허브로 다음 →2장. 따로 받을 게 없어요

CHAPTER 2
따로 받을 게 없어요
🚀 3줄 요약
  • 쌤보드 클래스는 쌤보드 프로그램 안에 이미 들어 있습니다.
  • 따로 내려받거나 설치할 파일이 없어요.
  • 쌤보드를 아직 안 까셨다면 그것만 설치하면 됩니다.

예전에는 HTML 파일을 따로 받아 배경화면 프로그램에 등록해야 했지만, 지금은 쌤보드 설치 프로그램 하나에 함께 담겨 있습니다. 쌤보드를 설치하셨다면 클래스도 이미 컴퓨터에 있는 상태예요.

💡 쌤보드를 아직 설치하지 않으셨다면
메일로 받으신 쌤보드_Setup_v1.0.exe를 먼저 설치해 주세요. 설치 방법은 쌤보드 가이드 2장에 있습니다 — 경고창 대처까지 함께 안내돼 있어요.
✅ 이미 설치하셨다면
바로 3장으로 가서 어느 모니터에 띄울지만 정하시면 됩니다.

CHAPTER 3
화면에 띄우기
🚀 3줄 요약
  • 작업표시줄 쌤보드 아이콘을 더블클릭해 설정 창을 엽니다.
  • 🖥️ 모니터에서 모니터를 클릭하고 쌤보드클래스를 고르면 끝.
  • 고르는 즉시 바탕화면에 적용됩니다.
  1. 1
    작업표시줄 우측 하단(🔔 알림 영역)의 쌤보드 아이콘을 더블클릭합니다.
  2. 2
    왼쪽 🖥️ 모니터를 누르고, 클래스를 띄울 모니터 그림을 클릭합니다.
  3. 3
    아래 "여기에 띄울 보드"에서 쌤보드클래스를 고릅니다. 바로 적용됩니다.
💡 모니터가 두 대라면
주로 보시는 모니터에는 쌤보드(대시보드), 아이들에게 보여줄 모니터에는 쌤보드클래스를 지정하시면 됩니다.
모니터 번호는 컴퓨터마다 달라요. 번호 대신 그림을 보고 고르세요 — 주 모니터에는 주 표시가 붙어 있습니다.
💡 모니터가 한 대인데 클래스만 쓰고 싶다면
그 모니터에 쌤보드클래스를 지정하시면 됩니다. 대시보드 없이 클래스만 써도 기능은 전부 동일해요.
✅ 예전에 하던 설정은 이제 필요 없어요
클릭이 씹히거나 재시작하면 설정이 날아가던 문제는 쌤보드 프로그램이 알아서 처리합니다. 따로 만질 게 없습니다.

CHAPTER 4
학생 명단 준비하기
🚀 3줄 요약
  • 방법은 2가지 — 구글시트 연동 또는 직접 입력.
  • 시트 연동은 쌤보드 본체와 같은 URL을 그대로 써도 됩니다 (새로 배포 불필요).
  • 둘 중 아무거나 골라도 자리배치·포인트·역할·뽑기 기능은 전부 동일하게 동작.
4-1. 방법 비교
항목시트연동 모드직접입력 모드
준비물구글시트 Apps Script URL없음 (학생 이름만 알면 됨)
설정 방법설정 ⚙ "기본" 탭에 URL 입력URL을 비워두고 textarea에 입력
새로 배포 필요?아니요 — 쌤보드 본체와 같은 URL 재사용해당 없음
시트에 무언가 기록되나요?아니요 — 읽기 전용(명렬표만 불러옴)해당 없음 (전부 로컬 저장)
4-2. 시트연동 모드 설정하기

이미 쌤보드 본체에서 구글시트를 연동해 쓰고 있다면, 그 URL을 그대로 쌤보드 클래스 설정에도 입력하면 됩니다. 쌤보드 클래스는 시트에서 학생 명렬표만 읽어올 뿐, 어떤 것도 시트에 기록하지 않으므로 Apps Script를 새로 배포하거나 코드를 수정할 필요가 없습니다.

  1. 1
    쌤보드 클래스 화면에서 ⚙ 설정 버튼을 클릭합니다.
  2. 2
    ⚙ 기본 탭에서 Apps Script URL 입력칸에 쌤보드 본체와 동일한 URL을 붙여넣습니다.
  3. 3
    학년·반을 입력하고 💾 저장을 누르면 명렬표가 자동으로 불러와집니다.
💡 아직 Apps Script를 배포해본 적이 없다면
쌤보드 본체 가이드의 5장 Apps Script 배포 ★를 먼저 따라 하세요. 거기서 만든 URL을 여기서도 그대로 쓰면 됩니다.
4-3. 직접입력 모드 설정하기

구글시트 없이 바로 쓰고 싶다면, URL 칸을 비워두고 설정 ⚙ 기본 탭의 "학생 직접 입력" textarea에 학생 이름을 한 줄에 한 명씩 입력합니다. 입력 즉시 자리배치 화면에 반영됩니다.

⚠️ 처음 열면 데모(가상) 학생 24명이 보여요
직접 입력 명단도 없고 시트 연동도 안 했다면 정상적으로 가상 학생 24명이 표시됩니다(?demo=1 기본값). 학생을 직접 입력하거나 시트를 연동하면 데모 데이터는 자동으로 사라집니다.

CHAPTER 5
자리배치 기본 화면
🚀 3줄 요약
  • 하단 🪑 탭 화면. 레이아웃은 ▦낱개 / ▥짝꿍 / ◳모둠 3종.
  • 🔁 자리변경을 켜야 좌석을 클릭해서 자리를 바꿀 수 있어요.
  • 자리변경을 끄면 좌석 클릭이 학생 포인트·역할 팝업으로 바뀝니다.

화면 하단에는 🪑 자리배치 / ⭐ 포인트 / 🎲 뽑기 3개 탭이 있습니다. 기본으로 열리는 🪑 자리배치 화면부터 살펴봅니다.

5-1. 레이아웃 3종

화면 위쪽 세그먼트 버튼으로 좌석 배열을 바꿀 수 있습니다.

버튼설명
▦ 낱개한 명씩 격자로 배열
▥ 짝꿍2석씩 묶어서 배열
◳ 모둠여러 명씩 묶음. −/＋ 버튼으로 모둠당 인원(2~8명) 조절
5-2. 자리변경 모드

화면 위쪽 🔁 자리변경 토글을 켜면 안내 배너("학생을 누르고 → 바꿀 자리(또는 빈자리)를 누르세요")가 나타나며, 좌석을 클릭하는 동작이 바뀝니다.

🔁 자리변경 상태좌석 클릭 시 동작
켜짐학생을 누르고 → 바꿀 자리를 누르면 두 자리가 맞바뀜. 미배치 풀의 학생도 좌석에 투입 가능
꺼짐좌석을 누르면 그 학생의 포인트·역할 팝업이 열림 (실수로 자리가 바뀌는 것을 방지)
💡 좌석 고정 📌
좌석 카드의 📌 아이콘을 누르면 그 자리를 고정할 수 있어요. 고정된 자리는 6장의 랜덤 자리뽑기에서 제외됩니다.

CHAPTER 6
랜덤 자리뽑기 & 성별 규칙
🚀 3줄 요약
  • 🔁 자리변경을 켜면 나타나는 🎲 자리 뽑기 버튼으로 랜덤 배치.
  • 슬롯머신 셔플 → 3·2·1 카운트다운 → 좌석 공개 연출.
  • 🚻 성별규칙 칩을 클릭하면 끄기→지그재그→짝꿍남녀 순환.
6-1. 자리 뽑기 연출

🔁 자리변경을 켜면 나타나는 🎲 자리 뽑기 버튼을 누르면 학생 이름이 빠르게 셔플되다가, 화면이 어두워지며 3·2·1 카운트다운 후 "짠!" 하고 좌석이 공개됩니다. 좌석은 하나씩 눌러서 공개하거나 ✨ 모두 공개 버튼으로 한 번에 열 수 있습니다.

💡 📌 고정된 자리, 🤫 떨어뜨리기 짝은 자동으로 보호됩니다
랜덤으로 자리를 뽑아도 📌로 고정해둔 좌석과 학생은 그대로 유지되고, 8장에서 설정한 "떨어뜨리고 싶은 짝"은 최대한 떨어지도록 알아서 재시도합니다.
6-2. 성별 자리 규칙

화면의 🚻 성별규칙 칩을 클릭할 때마다 규칙이 순환합니다. 설정 ⚙ "🤫 추가" 탭에서도 같은 방식으로 바꿀 수 있습니다.

규칙동작
끄기성별 관계없이 완전 랜덤
지그재그체크보드 패턴으로 남/여가 번갈아 앉도록 배치
짝꿍 남녀짝(2석)마다 남학생 1명+여학생 1명. ⇄ 칩으로 "남학생 왼쪽/여학생 왼쪽" 반전 가능
⚠️ 규칙을 끈 상태에서도 칩은 항상 보여요
성별규칙이 "끄기"여도 화면에 칩이 흐린 스타일로 계속 표시됩니다. 다시 켜고 싶을 때 바로 클릭할 수 있게 하기 위함입니다.

🎯 정해진 자리
🚀 3줄 요약
  • 랜덤처럼 보이지만 실제로는 항상 교사가 정한 배치가 나오는 기능.
  • ① 직접 자리 구성 → ② 설정에서 저장 → ③ 토글 ON, 3단계로 끝.
  • 학생들 눈에는 평소 자리뽑기와 똑같이 보입니다.

키가 너무 작거나 시력이 안 좋은 학생을 앞자리에, 친한 친구끼리는 떨어뜨리고 싶지만 "선생님이 일부러 갈라놨다"는 느낌은 주고 싶지 않을 때 쓰는 기능입니다. 화면에서는 평소처럼 슬롯머신 셔플과 카운트다운이 나오지만, 결과는 항상 미리 정해둔 배치로 고정됩니다.

7-1. 설정 방법 (3단계)
  1. 1
    🔁 자리변경 모드에서 원하는 자리 배치를 직접 만듭니다 (좌석 클릭-클릭으로 학생을 옮겨가며 구성).
  2. 2
    설정 ⚙ → "🎯 자리지정" 탭에서 "📌 지금 화면의 자리를 '정해진 자리'로 저장"을 클릭합니다.
  3. 3
    같은 탭의 "🎯 정해진 자리로 뽑기" 토글을 켭니다.

이후 🎲 자리 뽑기 버튼을 누르면 연출(셔플·카운트다운)은 그대로 나오지만, 결과는 항상 2단계에서 저장한 배치로 나옵니다. 저장된 배치를 다시 보고 싶으면 자리지정 탭의 미니 그리드 미리보기를 확인하세요. 삭제하고 싶다면 "저장된 자리 삭제" 버튼을 누르면 됩니다.

💡 학생 화면에는 아무 표시도 없습니다
성별규칙 칩처럼 화면에 흔적을 남기는 다른 기능과 달리, 정해진 자리 기능은 교사의 설정 화면에서만 상태를 확인할 수 있습니다. 학생들은 평소 자리뽑기와 구분할 수 없습니다.
⚠️ 정해진 자리는 성별 규칙보다 우선합니다
정해진 자리 토글이 켜져 있으면 6장의 성별규칙이나 8장의 떨어뜨리기 설정은 무시되고 저장된 배치가 그대로 적용됩니다. 저장된 배치에 없는 학생이나 좌석 범위 변화가 있으면 유효한 부분만 반영되고, 저장된 배치 자체가 없으면 토스트 안내 후 무작위로 대체됩니다.

떨어뜨리기
🚀 3줄 요약
  • 설정 ⚙ "🤫 추가" 탭에서 학생 2명을 짝지어 등록.
  • 랜덤 자리뽑기 때 등록된 두 학생이 짝·모둠·옆자리가 되지 않도록 자동 회피.
  • 화면에는 흔적이 남지 않는 교사 전용 설정.

같이 앉으면 자주 다투거나 서로 장난이 심해지는 학생 쌍을 등록해두면, 6장의 랜덤 자리뽑기가 그 둘을 짝·모둠·옆자리로 묶지 않도록 자동으로 여러 번 재시도해서 배치합니다.

설정 방법
  1. 1
    설정 ⚙ → "🤫 추가" 탭을 엽니다.
  2. 2
    학생 칩 그리드에서 떨어뜨리고 싶은 학생 2명을 클릭해 선택합니다.
  3. 3
    "＋ 떨어뜨리기 추가"를 누르면 목록에 등록됩니다. 목록은 8개씩 페이지로 넘겨볼 수 있어요(◀ n/total ▶).
💡 100% 보장은 아니에요
랜덤 배치는 최대 수백 번까지 재시도해서 떨어뜨리기 조건을 최대한 만족시키지만, 좌석 수가 적거나 조건이 너무 많으면 일부 위반이 남을 수 있습니다. 그럴 땐 🔁 자리변경 모드에서 직접 살짝 조정하면 됩니다.

칭찬 포인트
🚀 3줄 요약
  • 하단 ⭐ 포인트 탭에서 학생별 점수를 ±로 관리.
  • ✓ 여러 명 토글로 여러 학생에게 한 번에 같은 점수 부여 가능.
  • 🏆 포인트순 정렬로 랭킹(🥇🥈🥉) 확인.
9-1. 개별 포인트 부여

⭐ 포인트 탭의 기본 모드입니다. 학생 카드의 − / ＋ 버튼으로 1점씩 올리고 내립니다. 좌석 화면(🪑)에서도 자리변경 모드를 끈 상태로 좌석을 클릭하면 같은 학생 팝업에서 1~10 금액칩으로 점수를 줄 수 있습니다.

9-2. 여러 명 일괄 부여

상단의 ✓ 여러 명 토글을 켜면 카드 클릭이 선택(체크표시)으로 바뀝니다. 학생 여러 명을 선택한 뒤, 위에 나타나는 금액칩(1~10) 중 하나를 고르고 −차감 / ＋추가를 누르면 선택된 학생 전원에게 한 번에 적용됩니다.

9-3. 총점 · 랭킹 · 초기화
기능설명
총점 표시화면 상단에 "총점 N점 · M명" 표시. 다중선택 중이면 선택된 학생들의 합도 함께 표시
🏆 포인트순 정렬번호순 ↔ 점수 높은 순 토글. 1~3위는 🥇🥈🥉으로 표시
전체 초기화모든 학생의 포인트를 0으로 되돌림
💡 빠르게 두 번 누르면 한 번만 적용돼요
같은 학생에게 같은 방향(＋ 또는 −)으로 0.3초 안에 다시 누르면 중복 적용되지 않도록 막아줍니다. 빠르게 여러 번 점수를 주고 싶다면 1~10 금액칩이나 다중선택을 활용하세요.

1인 1역할
🚀 3줄 요약
  • 역할 추가·이름수정·삭제는 설정 ⚙ "🧹 역할" 탭에서.
  • 역할마다 이모지를 30종 팔레트에서 직접 선택 가능.
  • 배정은 좌석 클릭 또는 역할 탭에서 역할 이름 클릭 — 두 갈래.
  • 한 역할에 여러 명을 함께 배정할 수 있어요.
  • 🎲 랜덤 배정으로 한 번에 뽑을 수도 있습니다.
💡 하단에 역할 전용 탭은 없어요
1인 1역할은 별도 화면 탭이 아니라, 🪑 자리배치 화면의 🧹 역할 표시 토글(좌석 카드에 역할 칩 표시)과 설정 ⚙ "🧹 역할" 탭을 통해 관리합니다.
10-1. 역할 만들기 (이모지 직접 선택)
  1. 1
    설정 ⚙ → "🧹 역할" 탭을 엽니다.
  2. 2
    역할 추가 행 앞의 이모지 버튼을 눌러 30종 팔레트에서 원하는 아이콘을 고릅니다 (선택 안 하면 이름에서 자동으로 이모지가 추론됨).
  3. 3
    역할 이름(예: "우유 당번")을 입력하고 추가합니다. 목록은 8개씩 페이지로 넘겨볼 수 있어요.

기존에 만들어둔 역할의 이모지를 바꾸고 싶다면, 그 역할 행의 이모지 버튼을 다시 누르면 됩니다. 이름은 입력칸을 고쳐서 바로 수정(rename)할 수 있고, 배정된 학생은 그대로 유지됩니다.

10-2. 학생에게 역할 배정하기

두 가지 방법이 있습니다. 편한 쪽으로 쓰시면 됩니다.

방법이렇게이럴 때 편해요
학생 쪽에서 🪑 자리배치 화면에서 좌석을 클릭(자리변경 모드는 끈 채로) → 학생 팝업의 역할 칩을 눌러 켜고 끕니다. "이 학생에게 무슨 역할을 줄까?"
역할 쪽에서 설정 ⚙ → 🧹 역할 탭에서 역할 이름을 클릭 → 담당 학생 창이 열리면 학생 칩을 눌러 고릅니다. "이 역할은 누구누구 시킬까?"
10-3. 🎲 한 번에 랜덤 배정

학기 초나 매달 역할을 새로 정할 때, 일일이 고르지 않고 한 번에 뽑을 수 있습니다.

  1. 1
    설정 ⚙ → 🧹 역할 탭을 엽니다.
  2. 2
    맨 위 [🎲 역할 랜덤 배정]을 누릅니다.
  3. 3
    학생들이 섞여 역할마다 한 명씩 자동으로 정해집니다. 같은 학생이 두 역할을 맡지 않아요.
⚠️ 기존 배정은 모두 새로 뽑힌 학생으로 바뀝니다
여러 명을 배정해 두셨더라도 역할당 한 명으로 정리됩니다. 그래서 누르면 먼저 확인창이 떠요 — [취소]를 누르면 아무것도 바뀌지 않습니다.
역할 수가 학생 수보다 많으면, 남는 역할은 빈 채로 둡니다.
👥 한 역할에 여러 명을 함께 배정할 수 있어요
예를 들어 우유 당번에 세 명을 함께 넣어도 됩니다. 다른 학생에게 같은 역할을 줘도 앞사람이 해제되지 않아요 — 칩을 다시 누르면 그 학생만 빠집니다.
좌석 카드의 역할 칩에는 그 학생의 첫 번째 역할이 표시됩니다. 학생 팝업을 열면 맡은 역할 전체를 볼 수 있어요.
💡 좌석 카드에 역할 보이게 하기
🪑 화면 상단의 🧹 역할 표시 토글을 켜면 좌석 카드에 역할 이모지 칩이 함께 표시됩니다.

학생 뽑기
🚀 3줄 요약
  • 하단 🎲 뽑기 탭. 연출은 🎡돌림판 / 🃏카드 / 🎰슬롯 3가지.
  • 뽑힌 학생 제외가 기본 ON — 중복 없이 한 명씩 뽑기 가능.
  • 👥 대상 선택으로 일부 학생만 뽑기 풀에 포함할 수 있음.

발표자·당번·즉석 추첨이 필요할 때 쓰는 화면입니다. 발표·당번 배정처럼 즉흥적으로 쓰는 기능이라, 뽑힌 명단은 저장되지 않고 새로고침하면 초기화됩니다.

11-1. 연출 3종
모드설명
🎡 돌림판학생 수만큼 파이 섹터로 나뉜 룰렛이 돌다가 포인터가 가리키는 학생이 당첨
🃏 카드뒷면 카드들이 셔플되고, 아무 카드나 클릭하면 그 안에서 무작위 1명이 공개
🎰 슬롯이름이 빠르게 바뀌다가 점점 느려지며 한 명에서 정지
11-2. 뽑기 대상 좁히기
  • 뽑힌 학생 제외 토글(기본 ON) — 한 번 뽑힌 학생은 다시 뽑히지 않습니다.
  • 👥 대상 선택 — 학생 칩 그리드에서 일부만 선택하면, 그 학생들만으로 뽑기 풀이 좁혀집니다 (예: 10명 중 발표 안 한 8명만).
  • 🔄 초기화 — 뽑힌 명단을 비우고 처음부터 다시 시작합니다.
⚠️ 새로고침하면 뽑힌 명단이 사라져요
뽑힌 학생 목록은 일시적으로만 저장되는 정보라, 화면을 새로고침하거나 프로그램을 다시 켜면 초기화됩니다. 의도된 동작입니다.

1. ⏱️ 수업 타이머

⏱️ 버튼을 누르면 큰 숫자 타이머가 전체화면으로 뜹니다. 모둠 활동·시험·정리 시간 등에 활용하세요.

조작설명
프리셋1분 · 3분 · 5분 · 10분 버튼으로 즉시 시간 설정
−10초 / ＋10초세밀하게 시간을 늘리거나 줄이기
직접 입력분·초 칸에 숫자를 넣고 적용 (예: 12분 30초)
▶ 시작 / ⏸ 일시정지같은 버튼으로 시작·정지 토글, ↺ 리셋으로 초기화
💡 시간이 다 되면 알려줘요
0초에 도달하면 화면이 번쩍이고 알림음이 울려서, 판서 중이라 화면을 안 보고 있어도 종료를 알 수 있어요. 타이머 값은 즉석용이라 저장되지 않습니다.
2. 📋 알림장 (칠판 모드)

📋 버튼을 누르면 오늘의 숙제·준비물을 적는 칠판 모드가 열립니다. 하교 전에 크게 띄워 두면 학생들이 보고 알림장을 옮겨 적기 좋아요.

  • 아래 입력칸에 내용을 적고 Enter 또는 ＋ 추가로 한 줄씩 등록합니다.
  • 상단에 오늘 날짜가 표시되고, 전체 지우기로 한 번에 비울 수 있어요.
💡 알림장은 이 컴퓨터에만 저장돼요
알림장 내용은 쌤보드 클래스가 있는 이 PC에 로컬로만 저장됩니다(구글시트에 쓰지 않음). 날짜별 개념 없이 지우기 전까지 유지되니, 새 날에는 전체 지우기 후 다시 적어 주세요.
3. 📷 자리표 이미지 저장

📷 버튼을 누르면 현재 자리 배치를 이미지로 만들어 클립보드에 복사합니다. 보결 선생님께 전달하거나, 학급 게시판·문서에 붙여넣기(Ctrl+V)할 때 편해요.

💡 복사가 안 되는 환경이면 자동으로 미리보기 창이 떠요
바탕화면 위에서는 클립보드 복사가 막힐 수 있어, 자리표 이미지 미리보기 창이 대신 열립니다. 그 이미지를 우클릭 → 이미지 저장으로 내려받으면 됩니다.

  • 반 전체 칭찬 포인트 총점이 목표에 닿으면 달성! 🎉
  • 목표는 단계별로 여러 개 등록 가능 (예: 100점 → 300점 → 500점).
  • 화면 좌측 아래에 온도계 칩이 항상 떠서 진행률을 보여줘요.

칭찬 포인트(9장)를 학급 공동 목표와 연결하는 기능입니다. 개인 점수를 합친 반 전체 총점이 목표 점수에 도달하면 달성 축하 연출이 나와, 협동 동기부여에 좋아요.

1. 온도계 칩 — 항상 좌측 아래에

모든 화면 좌측 하단에 🌡️ 학급 목표 칩이 상시 표시됩니다. 채워지는 게이지로 다음 목표까지 얼마나 왔는지를 한눈에 보여줘요. 칩을 클릭하면 목표 관리 모달이 열립니다.

💡 보상 문구는 칩에 숨겨져 있어요
학생 시선이 분산되지 않도록, 칩에는 점수·진행률만 보이고 "무슨 보상인지"는 표시하지 않습니다. 보상 내용은 칩을 눌러 연 상세 모달에서만 확인돼요.
2. 목표 등록하기
  1. 1
    좌측 하단 🌡️ 학급 목표 칩을 클릭해 모달을 엽니다.
  2. 2
    새 목표 점수를 입력하거나 −50 · −10 · ＋10 · ＋50 버튼으로 맞춥니다.
  3. 3
    보상(달성하면 뭘 할까요?)을 적고 — 예: "과자 파티", "영화 보기" — ＋ 목표 추가를 누릅니다.

여러 개를 등록하면 점수가 낮은 목표부터 자동 정렬되어 단계별 목표가 됩니다. 필요 없어진 목표는 목록에서 삭제할 수 있어요.

🎉 달성 순간엔 축하 연출
총점이 한 목표 점수를 넘기는 순간 🎉 폭죽과 팡파레가 한 번 재생됩니다. 다음 단계 목표가 있으면 게이지가 자동으로 그 목표 기준으로 넘어가요.
⚠️ 목표 데이터도 이 PC에만 저장돼요
학급 목표는 자리·포인트와 마찬가지로 이 컴퓨터에 로컬로 저장되고 구글시트에는 쓰지 않습니다. 13장 백업 파일(쌤보드클래스_설정.json)에는 함께 담기니, 다른 PC로 옮길 땐 백업/복구를 이용하세요.

CHAPTER 12
화면 꾸미기 & 설정 정리
🚀 3줄 요약
  • 하단 메뉴가 작업표시줄에 가려지면 📐 하단 메뉴 여백으로 조절.
  • 설정 ⚙ 모달은 기본 / 역할 / 자리지정 / 추가 / 백업 5개 탭.
  • 탭마다 어떤 기능이 있는지 한눈에 정리해서 보여드려요.
12-1. 하단 메뉴 여백

바탕화면에 띄워 쓰다 보면 화면 가장 아래가 Windows 작업표시줄에 가려 하단 🪑⭐🎲 메뉴가 안 보일 수 있습니다. 이때 설정 ⚙ "🤫 추가" 탭 맨 위의 "📐 하단 메뉴 여백" −/＋ 버튼으로 여백을 조절하세요 (기본 56px, 0~160px 범위, 즉시 반영).

💡 이 값은 모니터별로 따로 저장돼요
작업표시줄 가려짐 정도는 화면마다 다를 수 있어서, 하단 여백 값은 동기화되는 데이터가 아니라 그 화면(기기)에만 로컬로 저장됩니다.
12-2. 설정 ⚙ 5탭 한눈에 보기
탭내용
⚙ 기본Apps Script URL / 학년·반 / 학생 직접 입력 / 좌석 열·행 수 / 자리·포인트·역할 초기화
🧹 역할1인 1역할 추가·이름수정·이모지 선택·삭제 (10장)
🎯 자리지정정해진 자리 저장·켜기/끄기·미리보기·삭제 (7장)
🤫 추가하단 메뉴 여백 / 🚻 성별 자리 규칙 / 떨어뜨리기 (6·8장)
💾 백업설정·자리·포인트·역할을 파일로 내보내기 / 가져오기 (13장)

CHAPTER 13
백업 & 복구
🚀 3줄 요약
  • 백업은 쌤보드 프로그램이 알아서 합니다 — 따로 하실 게 없어요.
  • 자리배치를 망쳤다면 ⏪ 어제로 되돌리기 한 번이면 됩니다.
  • 클래스 데이터는 이 컴퓨터에만 저장돼요 (구글시트에 안 씁니다).
⚠️ 클래스 데이터는 구글시트에 저장되지 않습니다
자리배치 · 포인트 · 역할 · 명단은 이 컴퓨터에만 보관됩니다. 구글시트는 학생 명단을 읽기만 하고, 자리나 포인트를 시트에 쓰지 않아요 (여러 선생님이 함께 쓰는 시트를 건드리지 않으려고 일부러 그렇게 했습니다).
그래서 쌤보드 대시보드와 달리, 새 PC로 옮길 때 구글시트만으로는 복원되지 않습니다.
13-1. 자동 백업 — 켜져 있으면 끝

쌤보드 설정 창의 ⚙ 옵션 → 설정 자동 백업이 켜져 있으면, 클래스 내용이 바뀔 때마다 컴퓨터에 자동으로 저장됩니다. 선생님이 따로 내보내기를 하실 필요가 없어요.

  • 잘 되고 있는지는 같은 화면의 "최근 자동 저장"에서 마지막 저장 시각으로 확인할 수 있습니다.
  • [📁 백업 폴더 열기]를 누르면 실제 파일도 볼 수 있어요.
13-2. ⏪ 어제로 되돌리기

자리를 새로 뽑았는데 영 아니거나, 실수로 명단을 지웠을 때 쓰는 되돌리기 버튼입니다.

  1. 1
    클래스 화면에서 설정 ⚙ → 💾 백업 탭을 엽니다.
  2. 2
    ⏪ 어제로 되돌리기를 누르면 어제 마지막 상태로 돌아갑니다.
💡 "어제 하루치"만 보관합니다
날짜가 바뀐 뒤 처음 저장될 때, 프로그램이 어제의 최종 상태를 한 벌 따로 보관해 둡니다. 그래서 되돌릴 수 있는 건 어제 상태 하나예요 — 그저께로는 못 돌아갑니다.
오늘 안에서 여러 번 바꾼 것을 취소하는 기능은 아닙니다.
13-3. 직접 파일로 챙기기

새 컴퓨터로 옮기거나, 더 안심하고 싶으실 때만 쓰시면 됩니다. 설정 ⚙ → 💾 백업 탭에서:

  • 💾 내보내기 — 지금 상태를 쌤보드클래스_설정.json 파일 하나로 저장합니다.
    앱스스크립트 주소 · 학생 명단 · 자리배치도 · 1인1역 · 포인트 · 떨어뜨리기 · 정해진 자리가 모두 담깁니다.
  • 📂 가져오기 — 저장해 둔 파일을 골라 되돌립니다.

파일 창은 쌤보드가 백업을 모아두는 폴더에서 열리니, 어디에 뒀는지 헤맬 일이 없습니다.

⚠️ 「가져오기」는 지금 상태를 덮어씁니다
불러온 파일의 내용으로 현재 자리배치·포인트가 통째로 바뀝니다. 되돌릴 수 없으니 복구 용도로만 쓰세요.
쌤보드 대시보드의 백업 파일을 잘못 고르면 "형식이 다르다"며 중단되니 걱정하지 않으셔도 됩니다.
💡 새 학년·새 학기에 초기화하고 싶다면
지금 상태를 먼저 내보내기 해두고 시작하세요. 작년 자리배치나 포인트를 다시 볼 일이 생길 수 있습니다.

CHAPTER 14
자주 묻는 질문 (FAQ)
쌤보드 본체 없이 쌤보드 클래스만 단독으로 써도 되나요?
네, 가능합니다. 1장 B 경로처럼 모니터 한 대에 쌤보드클래스만 지정하면 자리배치·포인트·1인1역할·뽑기 기능을 전부 단독으로 쓸 수 있어요.
듀얼모니터인데 양쪽 화면에 똑같은 게 떠요.
설정 창 🖥️ 모니터에서 모니터마다 다른 보드(한쪽은 쌤보드, 한쪽은 쌤보드클래스)를 골라주세요. 같은 보드를 두 모니터에 고르면 양쪽이 똑같이 보이고 설정도 공유하기 때문에 화면별로 다르게 보이게 할 수 없어요. 3장 #3-2를 참고해 두 파일을 각각 등록하세요.
다른 컴퓨터에서 열면 자리·포인트가 안 보여요 / 화면 간 동기화가 안 돼요.
의도된 동작입니다. 쌤보드 클래스는 자리·포인트·역할 데이터를 구글시트에 쓰지 않고 그 컴퓨터에 로컬로만 저장합니다 (공유 설정 시트 오염 방지). 그래서 PC가 다르면 자동으로 공유되지 않아요. 다른 컴퓨터로 옮기려면 13장의 백업 파일(쌤보드클래스_설정.json)을 내보내서 그쪽에서 가져오기 하면 됩니다.
예전엔 두 번 눌러야 동작했는데, 지금은요?
쌤보드 프로그램에서는 한 번에 눌립니다. 예전 배경화면 방식에서는 첫 클릭이 "창 활성화"로 소비돼 두 번 눌러야 했는데, 지금은 프로그램이 클릭을 화면에 직접 전달해서 그 문제가 없어요.
그래도 안 눌리는 곳이 있다면 알려주세요.
하단 🪑⭐🎲 메뉴가 화면 아래로 잘려서 안 보여요.
12장 #12-1의 "📐 하단 메뉴 여백" −/＋ 버튼으로 여백을 늘려보세요. 바탕화면에 띄우다 보니 Windows 작업표시줄에 가려져서 생기는 일입니다.
뽑힌 학생 명단이 새로고침하면 사라져요.
의도된 동작입니다. 학생 뽑기 명단은 그 순간의 즉석 추첨용이라 저장되지 않고, 새로고침하거나 프로그램을 다시 켜면 자동으로 초기화됩니다.
정해진 자리를 켰는데도 뽑기 연출이 평소와 똑같이 나와요.
의도된 동작입니다. 7장의 정해진 자리 기능은 슬롯 셔플·카운트다운 연출은 그대로 보여주고 결과만 미리 저장해둔 배치로 고정하는 기능이라, 학생들 눈에는 평소 랜덤 뽑기와 구분되지 않습니다.
구글시트 연동을 꼭 해야 하나요?
아니요. 4장의 직접입력 모드로 학생 이름만 입력해도 자리배치·포인트·역할·뽑기 전체 기능을 동일하게 사용할 수 있습니다.
PC를 껐다 켜거나 캐시를 지웠더니 자리·포인트가 사라졌어요.
쌤보드 클래스는 데이터를 이 PC에만 로컬로 저장하기 때문에, PC를 옮기거나 초기화하면 사라질 수 있어요. ① 쌤보드 설정 ⚙ 옵션 → 설정 자동 백업을 켜두고(기본값), ② 13장의 💾 내보내기로 파일을 한 벌 챙겨두시면 안전합니다. 자리배치를 망친 경우라면 ⏪ 어제로 되돌리기가 더 빠릅니다.
수업 타이머·알림장 내용은 저장되나요?
타이머는 즉석용이라 저장되지 않고 닫으면 초기화됩니다. 알림장은 이 PC에 로컬로 저장되지만(구글시트엔 안 씀), 날짜별로 자동 정리되지 않으니 새 날에는 전체 지우기 후 다시 적어 주세요. 디스크 캐시가 꺼져 있으면 재시작 시 알림장도 사라질 수 있어요.
학급 목표 온도계가 다른 컴퓨터에서는 안 보여요.
학급 목표(🌡️ 온도계)도 자리·포인트처럼 그 컴퓨터에 로컬로만 저장돼서 자동 공유되지 않습니다. 다른 PC로 옮기려면 13장의 백업 파일(쌤보드클래스_설정.json)을 내보내 그쪽에서 가져오기 하면 목표까지 함께 복원됩니다.
