CHAPTER 1
쌤보드 클래스란?
🚀 3줄 요약
  • 학생 자리배치·칭찬포인트·1인1역할·랜덤뽑기를 한 화면에 모은 학급운영 도구.
  • 사용법은 2가지 — 듀얼모니터 2번째 화면 / 단독 사용.
  • 어느 길로 가든 기능은 100% 동일, 화면에 띄우는 방식만 다름.

쌤보드 클래스는 학생 자리배치(랜덤·짝꿍·모둠), 칭찬 포인트, 1인 1역할, 학생 뽑기(돌림판·카드·슬롯)까지 교실 운영에 필요한 기능을 한 화면에 모은 도구입니다. 이미 쌤보드(교사용 대시보드)를 쓰고 있다면 그 짝꿍 제품이고, 안 쓰고 있어도 단독으로 전체 기능을 사용할 수 있습니다.

1-1. 나는 어떤 방법으로 써야 할까?

아래 2가지 중 본인 상황에 맞는 것을 먼저 골라보세요. 둘 다 Lively Wallpaper에 파일을 배경으로 등록해서 쓰는 방식이고, 기능은 완전히 같습니다.

🖥️🖥️
듀얼모니터
A. 듀얼모니터 2번째 화면

모니터가 2개라면 1번 화면엔 쌤보드 본체(대시보드), 2번 화면엔 쌤보드 클래스를 각각 배경으로 띄워 항시 보면서 운영할 수 있습니다. Lively에 서로 다른 파일 2개를 각각 등록해요.

🪑
단독 사용
B. 쌤보드 클래스만 단독

대시보드(날씨·캘린더·할일 등)까진 필요 없고 자리배치·포인트·뽑기 기능만 쓰고 싶다면, 쌤보드 클래스 파일 하나만 Lively 배경으로 등록해서 단독으로 사용합니다.

모니터 몇 개?2개 권장1개도 OK
학생 명단 연동직접 설정 (4장)직접 설정 (4장)

학생 명단을 새로 만들 필요 없이, 4장에서 쌤보드 본체와 같은 구글시트 URL을 그대로 입력하면 명렬표를 그대로 불러옵니다 (읽기 전용이라 본체 데이터에 영향 없음).

CHAPTER 2
Lively Wallpaper 설치
🚀 3줄 요약
  • Lively Wallpaper는 HTML 파일을 바탕화면으로 실행해주는 무료 앱.
  • LWP_Setup.exe 더블클릭 → "현재 사용자용"으로 설치.
  • 작업표시줄 우측 하단에 Lively 아이콘이 뜨면 완료.
💡 이미 쌤보드 본체를 Lively에 등록해서 쓰고 있다면
Lively는 이미 설치되어 있는 상태입니다. 이 장은 건너뛰고 3장으로 이동하세요.

Lively Wallpaper는 HTML 파일을 바탕화면으로 실행해 주는 무료 앱입니다. 쌤보드 클래스를 듀얼모니터 2번째 화면이나 단독 배경으로 쓰려면(1장의 두 경로 모두) Lively가 필요합니다.

설치 방법
  1. 1
    LWP_Setup.exe 파일을 더블클릭하여 실행합니다.
  2. 2
    설치 모드 선택 화면이 나타나면 '현재 사용자용으로 설치(추천)'를 클릭합니다.
  1. 3
    이후 화면은 기본값 그대로 두고 "Install" 버튼을 클릭합니다.
  2. 4
    설치가 완료되면 Lively Wallpaper가 자동으로 실행됩니다.
    작업표시줄 우측 하단(🔔 알림 영역)에 Lively 아이콘이 생기면 정상입니다.

CHAPTER 3
바탕화면에 띄우기
🚀 3줄 요약
  • Lively "+" 버튼으로 쌤보드클래스_ver1.0.html을 배경 등록.
  • 듀얼모니터면 두 모니터에 서로 다른 파일을 각각 지정.
  • 마우스 클릭이 씹히면 "마우스 상호 작용" 체크 + 디스크 캐시 켜기.
3-1. Lively에 배경화면으로 등록하기

Lively Wallpaper에 쌤보드클래스_ver1.0.html 파일을 배경화면으로 등록합니다. (듀얼모니터·단독 사용 모두 이 방법으로 시작합니다.)

  1. 1
    작업표시줄 우측 하단의 Lively 아이콘을 클릭하여 Lively Wallpaper를 엽니다.
  2. 2
    Lively 화면 왼쪽 상단의 "+" 버튼 (배경화면 추가)을 클릭합니다.
  1. 3
    팝업 창에서 "파일에서 열기" 또는 하단의 파일 탐색 버튼을 클릭합니다.
  2. 4
    파일 탐색기에서 쌤보드클래스_ver1.0.html 파일을 선택하고 "열기"를 클릭합니다.
  3. 5
    미리보기가 뜨면 "확인"을 클릭합니다.
⚠️ 듀얼모니터(A 경로)라면 — 두 모니터에 서로 다른 파일!
1번 모니터에는 쌤보드_ver2.4.html(본체), 2번 모니터에는 쌤보드클래스_ver1.0.html처럼 서로 다른 파일을 등록해야 합니다. 같은 파일을 두 모니터에 등록하면 Lively가 두 인스턴스의 설정값(Customise 값)을 공유하기 때문에, 한쪽을 바꾸면 다른 쪽도 똑같이 바뀌어 화면 분리가 안 됩니다.

📺 모니터별로 다르게 띄우는 순서

Lively 화면 오른쪽 위에 있는 🖥️ 디스플레이(모니터 모양) 아이콘으로 어느 모니터에 적용할지 고릅니다. (아래 사진의 빨간 네모 — [일반] 설정 탭에 따로 안 들어가도 메인 화면에서 바로 보여요.)

  1. 1
    Lively 화면 오른쪽 위의 🖥️ 디스플레이 아이콘을 클릭해, 배경을 바꿀 모니터(예: 1번)를 선택합니다.
  2. 2
    그 상태에서 1번 모니터용 파일(쌤보드_ver2.4.html)을 배경으로 적용합니다.
  3. 3
    다시 🖥️ 디스플레이 아이콘에서 2번 모니터를 선택한 뒤, 쌤보드클래스_ver1.0.html을 적용합니다.
  4. 4
    이미 등록한 배경이라면, 라이브러리에서 썸네일을 우클릭 → "디스플레이 선택"으로도 적용할 모니터를 바꿀 수 있습니다.
💡 단독 사용이라면 신경 안 써도 돼요
모니터 1개로 쌤보드 클래스만 쓰는 B 경로(단독 사용)라면 이 모니터별 지정 단계는 건너뛰어도 됩니다.
3-3. Lively 권장 설정

마우스 클릭이 씹히는 경우, 설정 패널 [배경화면] 탭 → "응용 프로그램이 포커싱된 경우 마우스 상호 작용"을 체크하세요. (쌤보드 본체와 동일한 설정 — 이미 체크해두었다면 그대로 둡니다.)

3-4. 재시작 후에도 데이터 유지 — 디스크 캐시 ✔ 필수

쌤보드 클래스는 자리배치·포인트·역할을 이 PC에 로컬로 저장합니다. 그런데 Lively가 브라우저 데이터를 메모리에만 두면 PC를 재시작할 때 데이터가 날아갈 수 있어요. 반드시 디스크 캐시를 켜세요.

설정 패널 [배경화면] 탭 → 웹 브라우저 섹션 → "디스크 캐시" 활성화

상태동작권장
활성화 브라우저 데이터(캐시·저장소)를 디스크에 보관 → PC 재시작 후에도 자리·포인트·역할 유지 ✔ 권장
비활성화 데이터가 메모리에만 남아 재시작 시 사라질 수 있음 ✘
💡 이중 안전장치
디스크 캐시를 켜도, 13장의 백업 파일(쌤보드클래스_설정.json)까지 만들어두면 PC 초기화·캐시 삭제 같은 사고에도 안전합니다. 둘 다 설정하는 것을 권장합니다.

CHAPTER 4
학생 명단 준비하기
🚀 3줄 요약
  • 방법은 2가지 — 구글시트 연동 또는 직접 입력.
  • 시트 연동은 쌤보드 본체와 같은 URL을 그대로 써도 됩니다 (새로 배포 불필요).
  • 둘 중 아무거나 골라도 자리배치·포인트·역할·뽑기 기능은 전부 동일하게 동작.
4-1. 방법 비교
항목시트연동 모드직접입력 모드
준비물구글시트 Apps Script URL없음 (학생 이름만 알면 됨)
설정 방법설정 ⚙ "기본" 탭에 URL 입력URL을 비워두고 textarea에 입력
새로 배포 필요?아니요 — 쌤보드 본체와 같은 URL 재사용해당 없음
시트에 무언가 기록되나요?아니요 — 읽기 전용(명렬표만 불러옴)해당 없음 (전부 로컬 저장)
4-2. 시트연동 모드 설정하기

이미 쌤보드 본체에서 구글시트를 연동해 쓰고 있다면, 그 URL을 그대로 쌤보드 클래스 설정에도 입력하면 됩니다. 쌤보드 클래스는 시트에서 학생 명렬표만 읽어올 뿐, 어떤 것도 시트에 기록하지 않으므로 Apps Script를 새로 배포하거나 코드를 수정할 필요가 없습니다.

  1. 1
    쌤보드 클래스 화면에서 ⚙ 설정 버튼을 클릭합니다.
  2. 2
    ⚙ 기본 탭에서 Apps Script URL 입력칸에 쌤보드 본체와 동일한 URL을 붙여넣습니다.
  3. 3
    학년·반을 입력하고 💾 저장을 누르면 명렬표가 자동으로 불러와집니다.
💡 아직 Apps Script를 배포해본 적이 없다면
쌤보드 본체 가이드의 5장 Apps Script 배포 ★를 먼저 따라 하세요. 거기서 만든 URL을 여기서도 그대로 쓰면 됩니다.
4-3. 직접입력 모드 설정하기

구글시트 없이 바로 쓰고 싶다면, URL 칸을 비워두고 설정 ⚙ 기본 탭의 "학생 직접 입력" textarea에 학생 이름을 한 줄에 한 명씩 입력합니다. 입력 즉시 자리배치 화면에 반영됩니다.

⚠️ 처음 열면 데모(가상) 학생 24명이 보여요
직접 입력 명단도 없고 시트 연동도 안 했다면 정상적으로 가상 학생 24명이 표시됩니다(?demo=1 기본값). 학생을 직접 입력하거나 시트를 연동하면 데모 데이터는 자동으로 사라집니다.

CHAPTER 5
자리배치 기본 화면
🚀 3줄 요약
  • 하단 🪑 탭 화면. 레이아웃은 ▦낱개 / ▥짝꿍 / ◳모둠 3종.
  • 🔁 자리변경을 켜야 좌석을 클릭해서 자리를 바꿀 수 있어요.
  • 자리변경을 끄면 좌석 클릭이 학생 포인트·역할 팝업으로 바뀝니다.

화면 하단에는 🪑 자리배치 / ⭐ 포인트 / 🎲 뽑기 3개 탭이 있습니다. 기본으로 열리는 🪑 자리배치 화면부터 살펴봅니다.

5-1. 레이아웃 3종

화면 위쪽 세그먼트 버튼으로 좌석 배열을 바꿀 수 있습니다.

버튼설명
▦ 낱개한 명씩 격자로 배열
▥ 짝꿍2석씩 묶어서 배열
◳ 모둠여러 명씩 묶음. −/＋ 버튼으로 모둠당 인원(2~8명) 조절
5-2. 자리변경 모드

화면 위쪽 🔁 자리변경 토글을 켜면 안내 배너("학생을 누르고 → 바꿀 자리(또는 빈자리)를 누르세요")가 나타나며, 좌석을 클릭하는 동작이 바뀝니다.

🔁 자리변경 상태좌석 클릭 시 동작

랜덤 자리뽑기 & 성별 규칙
🚀 3줄 요약
  • 🔁 자리변경을 켜면 나타나는 🎲 자리 뽑기 버튼으로 랜덤 배치.
  • 슬롯머신 셔플 → 3·2·1 카운트다운 → 좌석 공개 연출.
  • 🚻 성별규칙 칩을 클릭하면 끄기→지그재그→짝꿍남녀 순환.
6-1. 자리 뽑기 연출

🔁 자리변경을 켜면 나타나는 🎲 자리 뽑기 버튼을 누르면 학생 이름이 빠르게 셔플되다가, 화면이 어두워지며 3·2·1 카운트다운 후 "짠!" 하고 좌석이 공개됩니다. 좌석은 하나씩 눌러서 공개하거나 ✨ 모두 공개 버튼으로 한 번에 열 수 있습니다.

💡 📌 고정된 자리, 🤫 떨어뜨리기 짝은 자동으로 보호됩니다
랜덤으로 자리를 뽑아도 📌로 고정해둔 좌석과 학생은 그대로 유지되고, 8장에서 설정한 "떨어뜨리고 싶은 짝"은 최대한 떨어지도록 알아서 재시도합니다.
6-2. 성별 자리 규칙

화면의 🚻 성별규칙 칩을 클릭할 때마다 규칙이 순환합니다. 설정 ⚙ "🤫 추가" 탭에서도 같은 방식으로 바꿀 수 있습니다.

규칙동작
끄기성별 관계없이 완전 랜덤
지그재그체크보드 패턴으로 남/여가 번갈아 앉도록 배치
짝꿍 남녀짝(2석)마다 남학생 1명+여학생 1명. ⇄ 칩으로 "남학생 왼쪽/여학생 왼쪽" 반전 가능
⚠️ 규칙을 끈 상태에서도 칩은 항상 보여요
성별규칙이 "끄기"여도 화면에 칩이 흐린 스타일로 계속 표시됩니다. 다시 켜고 싶을 때 바로 클릭할 수 있게 하기 위함입니다.

CHAPTER 7 · NEW
🎯 정해진 자리
🚀 3줄 요약
  • 랜덤처럼 보이지만 실제로는 항상 교사가 정한 배치가 나오는 기능.
  • ① 직접 자리 구성 → ② 설정에서 저장 → ③ 토글 ON, 3단계로 끝.
  • 학생들 눈에는 평소 자리뽑기와 똑같이 보입니다.

키가 너무 작거나 시력이 안 좋은 학생을 앞자리에, 친한 친구끼리는 떨어뜨리고 싶지만 "선생님이 일부러 갈라놨다"는 느낌은 주고 싶지 않을 때 쓰는 기능입니다. 화면에서는 평소처럼 슬롯머신 셔플과 카운트다운이 나오지만, 결과는 항상 미리 정해둔 배치로 고정됩니다.

7-1. 설정 방법 (3단계)
  1. 1
    🔁 자리변경 모드에서 원하는 자리 배치를 직접 만듭니다 (좌석 클릭-클릭으로 학생을 옮겨가며 구성).
  2. 2
    설정 ⚙ → "🎯 자리지정" 탭에서 "📌 지금 화면의 자리를 '정해진 자리'로 저장"을 클릭합니다.
  3. 3
    같은 탭의 "🎯 정해진 자리로 뽑기" 토글을 켭니다.

이후 🎲 자리 뽑기 버튼을 누르면 연출(셔플·카운트다운)은 그대로 나오지만, 결과는 항상 2단계에서 저장한 배치로 나옵니다. 저장된 배치를 다시 보고 싶으면 자리지정 탭의 미니 그리드 미리보기를 확인하세요. 삭제하고 싶다면 "저장된 자리 삭제" 버튼을 누르면 됩니다.

💡 학생 화면에는 아무 표시도 없습니다
성별규칙 칩처럼 화면에 흔적을 남기는 다른 기능과 달리, 정해진 자리 기능은 교사의 설정 화면에서만 상태를 확인할 수 있습니다. 학생들은 평소 자리뽑기와 구분할 수 없습니다.
⚠️ 정해진 자리는 성별 규칙보다 우선합니다
정해진 자리 토글이 켜져 있으면 6장의 성별규칙이나 8장의 떨어뜨리기 설정은 무시되고 저장된 배치가 그대로 적용됩니다. 저장된 배치에 없는 학생이나 좌석 범위 변화가 있으면 유효한 부분만 반영되고, 저장된 배치 자체가 없으면 토스트 안내 후 무작위로 대체됩니다.

떨어뜨리기
🚀 3줄 요약

같이 앉으면 자주 다투거나 서로 장난이 심해지는 학생 쌍을 등록해두면, 6장의 랜덤 자리뽑기가 그 둘을 짝·모둠·옆자리로 묶지 않도록 자동으로 여러 번 재시도해서 배치합니다.

설정 방법
  1. 1
    설정 ⚙ → "🤫 추가" 탭을 엽니다.
  2. 2
    학생 칩 그리드에서 떨어뜨리고 싶은 학생 2명을 클릭해 선택합니다.
  3. 3
    "＋ 떨어뜨리기 추가"를 누르면 목록에 등록됩니다. 목록은 8개씩 페이지로 넘겨볼 수 있어요(◀ n/total ▶).
💡 100% 보장은 아니에요
랜덤 배치는 최대 수백 번까지 재시도해서 떨어뜨리기 조건을 최대한 만족시키지만, 좌석 수가 적거나 조건이 너무 많으면 일부 위반이 남을 수 있습니다. 그럴 땐 🔁 자리변경 모드에서 직접 살짝 조정하면 됩니다.

칭찬 포인트
🚀 3줄 요약
  • 하단 ⭐ 포인트 탭에서 학생별 점수를 ±로 관리.
  • ✓ 여러 명 토글로 여러 학생에게 한 번에 같은 점수 부여 가능.
  • 🏆 포인트순 정렬로 랭킹(🥇🥈🥉) 확인.
9-1. 개별 포인트 부여

⭐ 포인트 탭의 기본 모드입니다. 학생 카드의 − / ＋ 버튼으로 1점씩 올리고 내립니다. 좌석 화면(🪑)에서도 자리변경 모드를 끈 상태로 좌석을 클릭하면 같은 학생 팝업에서 1~10 금액칩으로 점수를 줄 수 있습니다.

9-2. 여러 명 일괄 부여

상단의 ✓ 여러 명 토글을 켜면 카드 클릭이 선택(체크표시)으로 바뀝니다. 학생 여러 명을 선택한 뒤, 위에 나타나는 금액칩(1~10) 중 하나를 고르고 −차감 / ＋추가를 누르면 선택된 학생 전원에게 한 번에 적용됩니다.

9-3. 총점 · 랭킹 · 초기화
기능설명
총점 표시화면 상단에 "총점 N점 · M명" 표시. 다중선택 중이면 선택된 학생들의 합도 함께 표시
🏆 포인트순 정렬번호순 ↔ 점수 높은 순 토글. 1~3위는 🥇🥈🥉으로 표시
전체 초기화모든 학생의 포인트를 0으로 되돌림
💡 빠르게 두 번 누르면 한 번만 적용돼요
같은 학생에게 같은 방향(＋ 또는 −)으로 0.3초 안에 다시 누르면 중복 적용되지 않도록 막아줍니다. 빠르게 여러 번 점수를 주고 싶다면 1~10 금액칩이나 다중선택을 활용하세요.

CHAPTER 13
백업 & 복구
🚀 3줄 요약
  • 쌤보드 클래스 데이터는 이 PC에만 저장돼요 (구글시트에 안 씀).
  • 설정 ⚙ 💾 백업 탭에서 쌤보드클래스_설정.json 파일로 내보내기.
  • 그 파일을 HTML과 같은 폴더에 두면, 데이터가 비었을 때 자동 복구!
⚠️ 왜 백업이 필요한가요?
쌤보드 클래스는 자리배치·포인트·역할·명단을 이 컴퓨터에만 로컬로 저장합니다 (구글시트는 명단을 읽기만 하고, 공유 설정 시트를 더럽히지 않으려고 자리·포인트는 쓰지 않아요). 그래서 PC를 초기화하거나 브라우저 캐시를 지우면 데이터가 사라질 수 있습니다. 3장의 디스크 캐시 + 이 장의 백업 파일을 둘 다 해두면 안전합니다.
13-1. 백업 파일 만들기 (내보내기)
  1. 1
    설정 ⚙ → 💾 백업 탭을 엽니다.
  2. 2
    "💾 내보내기" 버튼을 누르면 쌤보드클래스_설정.json 파일이 저장됩니다. (저장 위치를 물어보면 원하는 폴더 선택, 아니면 다운로드 폴더에 생성)
  3. 3
    이 파일에는 앱스스크립트 주소 · 학생 명단 · 자리배치도 · 1인 1역할 · 포인트 · 떨어뜨리기 · 정해진 자리가 모두 담깁니다. (하단 메뉴 여백·소리는 화면마다 달라서 제외)
13-2. 자동 복구 — 같은 폴더에 두기 (강력 추천)

방금 만든 쌤보드클래스_설정.json 파일을 쌤보드클래스_ver1.0.html과 같은 폴더에 두세요. 그러면 PC 초기화·캐시 삭제 등으로 로컬 데이터가 비어 있을 때, 배경화면을 켜자마자 이 파일을 읽어 자동으로 복구합니다.

💡 최신본은 절대 안 덮어써요
자동 복구는 로컬에 데이터가 없을 때만 작동합니다. 평소처럼 데이터가 있으면 백업 파일을 건드리지 않으니, 오래된 파일이 최신 자리배치를 덮어쓸 걱정은 없어요. 대신 큰 변경을 한 날에는 다시 내보내기로 파일을 갱신해두면 가장 안전합니다.
13-3. 다른 PC로 옮기거나 되돌리기 (가져오기)

설정 ⚙ → 💾 백업 탭 → "📂 가져오기" 버튼 → 저장해 둔 쌤보드클래스_설정.json 파일을 선택하면 즉시 복원됩니다. 새 컴퓨터로 옮길 때나, 실수로 초기화했을 때 이렇게 되돌리세요.

⚠️ 구글시트로는 백업되지 않아요
쌤보드 본체와 달리, 쌤보드 클래스는 자리·포인트 데이터를 구글시트에 저장하지 않습니다 (공유 설정 시트 오염 방지). 따라서 이 백업 파일이 유일한 백업 수단입니다. 꼭 한 번 만들어 두세요.

CHAPTER 14
자주 묻는 질문 (FAQ)
쌤보드 본체 없이 쌤보드 클래스만 단독으로 써도 되나요?
네, 가능합니다. 1장 B 경로처럼 쌤보드클래스_ver1.0.html 파일 하나만 Lively 배경으로 등록하면 자리배치·포인트·1인1역할·뽑기 기능을 전부 단독으로 쓸 수 있어요.
듀얼모니터인데 양쪽 화면에 똑같은 게 떠요.
두 모니터에 서로 다른 파일(쌤보드 본체 ≠ 쌤보드 클래스)을 등록해야 합니다. Lively는 같은 파일을 두 모니터에 등록하면 설정값(Customise 값)을 공유하기 때문에 화면별로 다르게 보이게 할 수 없어요. 3장 #3-2를 참고해 두 파일을 각각 등록하세요.
다른 컴퓨터에서 열면 자리·포인트가 안 보여요 / 화면 간 동기화가 안 돼요.
의도된 동작입니다. 쌤보드 클래스는 자리·포인트·역할 데이터를 구글시트에 쓰지 않고 그 컴퓨터에 로컬로만 저장합니다 (공유 설정 시트 오염 방지). 그래서 PC가 다르면 자동으로 공유되지 않아요. 다른 컴퓨터로 옮기려면 13장의 백업 파일(쌤보드클래스_설정.json)을 내보내서 그쪽에서 가져오기 하면 됩니다.
화면을 클릭해도 한 번에 안 눌리고 두 번 눌러야 동작해요.
Lively Wallpaper가 배경화면을 OS 바탕화면 레이어에 띄우는 특성상, 첫 클릭이 "창 활성화"로 소비되고 두 번째 클릭부터 실제로 전달되는 경우가 있습니다. Lively 환경의 알려진 특성이라 더블 클릭이 정상 동작이에요.
하단 🪑⭐🎲 메뉴가 화면 아래로 잘려서 안 보여요.
12장 #12-1의 "📐 하단 메뉴 여백" −/＋ 버튼으로 여백을 늘려보세요. Lively로 실행할 때 Windows 작업표시줄에 가려지는 경우 발생합니다.
뽑힌 학생 명단이 새로고침하면 사라져요.
의도된 동작입니다. 학생 뽑기 명단은 그 순간의 즉석 추첨용이라 저장되지 않고, 새로고침이나 Lively 재시작 시 자동으로 초기화됩니다.
정해진 자리를 켰는데도 뽑기 연출이 평소와 똑같이 나와요.
의도된 동작입니다. 7장의 정해진 자리 기능은 슬롯 셔플·카운트다운 연출은 그대로 보여주고 결과만 미리 저장해둔 배치로 고정하는 기능이라, 학생들 눈에는 평소 랜덤 뽑기와 구분되지 않습니다.
구글시트 연동을 꼭 해야 하나요?
아니요. 4장의 직접입력 모드로 학생 이름만 입력해도 자리배치·포인트·역할·뽑기 전체 기능을 동일하게 사용할 수 있습니다.
PC를 껐다 켜거나 캐시를 지웠더니 자리·포인트가 사라졌어요.
쌤보드 클래스는 데이터를 이 PC에만 로컬로 저장하기 때문에, Lively의 디스크 캐시(3장 #3-4)가 꺼져 있으면 재시작 시 날아갈 수 있어요. ① 디스크 캐시를 켜고, ② 13장의 백업 파일(쌤보드클래스_설정.json)을 만들어 HTML과 같은 폴더에 두면 자동 복구까지 됩니다. 둘 다 해두는 걸 권장해요.
